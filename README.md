# airgap-rca

Grounded root cause analysis on offline edge accelerators.

## Status

Total 8 Blocks to satisfy this project. Block one (Immutable logs) which is a synthetic logs and hybrid observation, investigation, action and retest are done within it. Block two (chunks for retrieval) which evidence chunks and use for local vector search and keyword indexes which is our third block.
